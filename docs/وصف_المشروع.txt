# تطبيق القرآن الكريم - وصف المشروع

## المميزات الرئيسية للتطبيق

### 1. قراءة القرآن الكريم 📖
- **الوصف**: واجهة متكاملة لقراءة القرآن الكريم مع دعم عرض الصفحات بالرسم العثماني
- **الملفات المرتبطة**: `lib/features/read_quran`
- **المميزات الفرعية**:
  - عرض النص القرآني بخطوط متعددة
  - علامات الوقف والتجويد
  - إمكانية التحكم في حجم الخط
  - دعم وضع القراءة الليلي

### 2. الاستماع للقرآن الكريم 🎧
- **الوصف**: نظام متكامل للاستماع للقرآن الكريم بأصوات مختلف القراء
- **الملفات المرتبطة**: `lib/features/quran_audio`
- **المميزات**:
  - تشغيل الصوت مع إمكانية التحكم في التشغيل
  - دعم التحميل للاستماع بدون إنترنت
  - قائمة متنوعة من القراء
  - عرض كلمات الآيات أثناء الاستماع

### 3. مواقيت الصلاة ⏰
- **الوصف**: نظام دقيق لعرض مواقيت الصلاة حسب الموقع الجغرافي
- **الملفات المرتبطة**: `lib/features/prayer_time`
- **المميزات**:
  - تحديد المواقيت تلقائياً حسب الموقع
  - إشعارات للصلوات
  - عرض الوقت المتبقي للصلاة القادمة
  - دعم مختلف طرق الحساب

### 4. اتجاه القبلة 🕋
- **الوصف**: بوصلة إلكترونية لتحديد اتجاه القبلة
- **الملفات المرتبطة**: `lib/features/qiblah`
- **المميزات**:
  - تحديد اتجاه القبلة بدقة
  - خريطة تفاعلية
  - عرض المسافة إلى الكعبة المشرفة

### 5. الأذكار والأدعية 📿
- **الوصف**: مجموعة شاملة من الأذكار والأدعية اليومية
- **الملفات المرتبطة**: 
  - `lib/features/thikr`
  - `lib/features/my_adia`
- **المميزات**:
  - أذكار الصباح والمساء
  - أذكار بعد الصلاة
  - عداد للتسبيح
  - إمكانية إضافة أدعية مخصصة

### 6. البحث المتقدم 🔍
- **الوصف**: محرك بحث متقدم في القرآن الكريم
- **الملفات المرتبطة**: `lib/features/search`
- **المميزات**:
  - البحث في النص القرآني
  - البحث بالكلمات المفتاحية
  - نتائج بحث فورية
  - إمكانية البحث بدون تشكيل

### 7. العلامات المرجعية 🔖
- **الوصف**: نظام حفظ وتنظيم العلامات المرجعية
- **الملفات المرتبطة**: `lib/features/bookmark`
- **المميزات**:
  - حفظ مواضع القراءة
  - تصنيف العلامات
  - إضافة ملاحظات
  - مزامنة العلامات

### 8. أسماء الله الحسنى ✨
- **الوصف**: عرض وشرح أسماء الله الحسنى
- **الملفات المرتبطة**: `lib/features/allh_name`
- **المميزات**:
  - شرح مفصل لكل اسم
  - تفسير معاني الأسماء
  - صوتيات للنطق الصحيح

### 9. المكتبة الإسلامية 📚
- **الوصف**: مكتبة متكاملة للكتب والمراجع الإسلامية
- **الملفات المرتبطة**: `lib/features/books`
- **المميزات**:
  - تصفح الكتب
  - تحميل للقراءة بدون إنترنت
  - تنظيم حسب التصنيفات
  - إمكانية البحث في المحتوى

### 10. الوضع غير المتصل 📱
- **الوصف**: دعم كامل للعمل بدون إنترنت
- **الملفات المرتبطة**: `lib/features/offline`
- **المميزات**:
  - تخزين البيانات محلياً
  - مزامنة تلقائية عند توفر الإنترنت
  - إدارة المساحة التخزينية

## الهيكل التقني للمشروع

### المكونات الأساسية:
- استخدام Flutter Bloc لإدارة حالة التطبيق
- قاعدة بيانات SQLite للتخزين المحلي
- دعم التعريب الكامل
- تصميم متجاوب مع مختلف أحجام الشاشات
- دعم الوضع الليلي والوضع النهاري
- معالجة متقدمة للصوتيات والوسائط

### التقنيات المستخدمة:
- Flutter SDK ≥3.3.3
- مكتبات متخصصة للصوتيات والتنبيهات
- خطوط عربية متعددة للعرض المثالي
- نظام تخزين وإدارة الملفات
- معالجة متقدمة للموقع الجغرافي

### ملاحظات تقنية:
- التطبيق يدعم أندرويد و iOS
- يستخدم نمط التصميم المعماري Clean Architecture
- يدعم التحديثات التلقائية
- يتضمن نظام تعامل مع الأخطاء وإعادة المحاولة
