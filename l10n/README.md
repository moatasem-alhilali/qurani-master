# Translations (l10n)

The app speaks 6 languages: **ar** (source), **ur**, **bn**, **id**, **fa**, **tr**.
Code uses Flutter's official `gen-l10n` (ARB → typed `L10n` class).

## Where things live

| Path | Who edits it |
| --- | --- |
| `l10n/fragments/<area>.json` | Arabic source strings, one file per feature area. **Edit these.** |
| `lib/l10n/app_ar.arb` | Generated by `tool/l10n_sync.py` from the fragments. Never edit by hand. |
| `lib/l10n/app_{ur,bn,id,fa,tr}.arb` | Translations. Edited by translators. |
| `lib/l10n/app_localizations*.dart` | Generated by `flutter gen-l10n`. Never edit. |
| `lib/l10n/l10n.dart` | `AppLanguage`, `context.l10n`, `L10nService`, helpers. |

After changing any fragment or ARB:

```
python tool/l10n_sync.py            # merge + validate + regenerate
python tool/l10n_sync.py --report   # + untranslated/stale keys per language
```

## Using strings

```dart
import 'package:quran_app/l10n/l10n.dart';

Text(context.l10n.commonSave)                       // inside widgets
DateFormat.yMMMd(context.localeCode).format(date)   // never a literal 'ar'
L10nService.current.prayerFajr                      // notifications, widgets, background isolates (no BuildContext)
context.l10n.hijriMonth(9)                          // Hijri month names
context.l10n.prayerName('asr')                      // prayer names by key
```

Reuse the shared keys in `common.json` (`commonSave`, `commonCancel`,
`prayerFajr`, `hijriMonth1`…) instead of adding duplicates.

## Rules for extracting strings

1. **Keys**: lowerCamelCase, prefixed with the area (`prayerTimeNextLabel`,
   `settingsNotificationsTitle`). Unique across all fragments — the sync script
   fails on duplicates.
2. **Add `@key.description`** whenever the context is not obvious (where it is
   shown, what a placeholder holds). Translators see only the ARB.
3. **Placeholders** instead of concatenation:
   `"prayerTimeRemaining": "متبقٍ {time}"` with
   `"placeholders": {"time": {"type": "String"}}`. Never build sentences with `+`.
4. **Plurals** use ICU and always include `other`:
   `"{count, plural, =0{…} =1{…} =2{…} few{…} many{…} other{…}}"` with
   `count` typed `int`.
5. **Religious text stays Arabic.** Quran, adhkar, duas, hadith, the 99 Names,
   ruqyah — and anything loaded from JSON/DB content — is *not* translated.
   Only the UI around it is. Keep `Directionality(textDirection: TextDirection.rtl)`
   only around that Arabic content.
6. **Direction-neutral layout**, because bn/id/tr are left-to-right:
   - `EdgeInsets.only(left/right)` → `EdgeInsetsDirectional.only(start/end)`
   - `Alignment.centerRight` → `AlignmentDirectional.centerStart` (etc.)
   - `Positioned(left/right)` → `PositionedDirectional(start/end)`
   - `TextAlign.right` → `TextAlign.start`
   - Remove forced `Directionality(rtl)` / `textDirection: TextDirection.rtl`
     around UI chrome.
   - Directional icons (back/forward arrows, chevrons) must follow
     `Directionality.of(context)`.
7. **Dates and numbers**: pass `context.localeCode` (or
   `L10nService.savedLanguage.code`) to `DateFormat` / `NumberFormat`.
8. **Not user-facing → leave it**: log messages, analytics event names, cache
   keys, asset paths, route names, debug prints.
9. **Brand**: `appName` is «طمأنينة»; Latin-script languages write "Tamaneena".
